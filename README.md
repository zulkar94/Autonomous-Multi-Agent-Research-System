# Autonomous-Multi-Agent-Research-System
Autonomous multi-agent research system. Six agents (Planner→Searcher→Analyst→Verifier→DebateModerator→Synthesizer) plan, search, extract, verify, debate, cite. FastAPI + React/TS, Argon2id+JWT auth, SSRF guard, prompt-injection fencing, SSE live trace, Docker/CI, 48 tests @ 82% coverage. Runs offline via mock providers.
